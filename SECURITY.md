# Security

Security fixes target the latest published version. Until the first publication,
use the latest `main` commit and review the first-release limits in
`docs/validation.md`.

Report vulnerabilities privately through
[GitHub security reporting](https://github.com/r4sky0/sphinx-autodoc-java/security/advisories/new).
Include a minimal reproducer, the affected version, and Python/JDK versions.
Please keep exploit details out of public issues while a fix is being prepared.
