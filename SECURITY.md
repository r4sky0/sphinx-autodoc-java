# Security

Security fixes target the latest version published on
[PyPI](https://pypi.org/project/sphinx-java-autodoc/). Known limits are recorded in
`docs/compatibility.rst`.

Report vulnerabilities privately through
[GitHub security reporting](https://github.com/r4sky0/sphinx-java-autodoc/security/advisories/new).
Include a minimal reproducer, the affected version, and Python/JDK versions.
Please keep exploit details out of public issues while a fix is being prepared.
